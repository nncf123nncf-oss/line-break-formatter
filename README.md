# 1文1行整形（line-break-formatter）

文章を貼ると、1文ごとに改行し、段落の間に空行を入れた形に整える静的ページです（100日100プロダクト Day068）。ボタン1つで、句読点を外す・付けるを切り替えられます。

- 文章はブラウザの中だけで処理し、サーバーには送信せず、保存もしません（通信は閲覧数の計測のみ）
- 20000字まで。並べ方は X（空行なし）／Substack（文ごとに空行）／LinkedIn（2文ごとに空行）
- 句読点を外す→付けるは、外す前の位置にそのまま戻ります。最初から句読点がない文章には、行末に「。」だけを付けます（「、」は自動で付けません）
- 文の切れ目は規則での推定です。誤って切る・切り損ねることがあります。誤字・言い換えは扱いません

## 検算
```
node source/run-checks.js   # 整形ルールの検算
node source/e2e.js          # Chrome headless での画面の検算（Chrome が必要）
python source/build.py      # source/index.src.html から index.html を作る
```
